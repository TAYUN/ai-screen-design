# 开发日志

本目录记录项目开发过程中的阶段性进度。每次完成一个可独立说明的功能或问题处理时，新增一篇以日期和主题命名的日志；日志按时间倒序维护在下方索引中。

## 记录原则

- 记录实际变更、设计取舍、验证结果和后续事项，便于回顾与交接。
- 区分“已完成”“待确认”和“未验证”；未提交的工作区改动只代表进行中的开发内容。
- 一篇日志聚焦一个主题。跨多日的工作在原日志中追加进展，或拆分为新的阶段记录。

## 命名规则

文件名格式：`YYYY-MM-DD-主题.md`，主题使用小写英文短横线，例如：`2026-08-15-property-panel.md`。

## 记录模板

```md
# 主题名称

- 日期：YYYY-MM-DD
- 状态：进行中 / 已完成 / 阻塞

## 目标

说明本次要解决的问题或交付内容。

## 已完成

- 具体改动及影响范围。

## 设计与取舍

- 关键实现方式及选择原因。

## 验证

- 已执行的命令、手工验证步骤及结果。
- 尚未验证的部分。

## 后续事项

- 待办、已知限制或下一步。
```
