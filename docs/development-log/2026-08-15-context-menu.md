# 画布物料右键菜单

- 日期：2026-08-15
- 状态：阻塞

## 目标

为画布中的物料节点增加右键菜单，提供复制、删除、置顶、置底和锁定等基础操作。

## 已完成

- 在 `MaterialSchema` 中增加 `locked` 字段。
- 在编辑器 Store 中增加复制、删除、置顶、置底和切换锁定的方法。
- 在画布节点上接入 Element Plus 下拉菜单，并提供上述操作入口。
- 锁定节点暂时通过排除 Moveable 目标的方式限制拖拽和缩放。
- 复制节点时生成新的 UUID，并将位置向右下方偏移 20px。

## 设计与取舍

- 右键菜单当前通过当前选中节点执行命令，未将菜单触发节点直接传入命令处理函数。
- 画布使用节点数组索引计算 `zIndex`，置顶和置底通过调整 `nodes` 数组顺序实现，不新增独立的层级字段。
- 当前菜单按单节点操作设计，多选场景尚未定义批量操作规则。

## 验证

- 已检查画布、编辑器 Store、物料 schema 和现有图层面板的实现关系。
- 执行 `pnpm type-check` 未通过。
- 类型检查失败原因是现有物料定义没有补充必填的 `locked` 字段。
- 尚未完成浏览器交互验证和自动化测试。
