# 撤销重做基础实现

- 日期：2026-08-17
- 状态：已完成

## 目标

为属性面板的字段修改增加基础撤销和重做能力，并将操作接入编辑器工具栏。

## 已完成

- 新增 `src/composables/useUndoRedo.ts`，维护共享的撤销栈和重做栈。
- 通过 `applyChange` 统一记录字段修改前后的值，并在新修改发生时清空重做栈。
- 在属性表单中使用 `applyChange` 替代直接写入，保留原有字段路径更新方式。
- 在左侧工具栏接入撤销、重做按钮及可用状态显示。
- 为撤销重做组合式函数补充职责、历史记录结构和栈流转说明。

## 设计与取舍

- 历史栈放在组合式函数模块作用域中，使属性表单和工具栏实例共享同一份操作历史。
- 每条记录保存 `target`、`key`、`oldValue` 和 `newValue`，复用现有 `getValue` / `setValue` 处理嵌套字段路径。
- 当前实现按单字段修改记录操作，尚未合并连续输入事件或限制历史记录数量。
